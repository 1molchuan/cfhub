加入:在你的线路上跑一个探针

探针每小时用 ECH 实测一批 Cloudflare IP(和浏览器访问 Cloudflare 站点的方式相同),把结果上报到这里。同一运营商有足够多的探针后,edge DoH 就会给这个运营商的用户返回更适合他们的优选 IP。

  • 只需要一台能长期开机的 Linux(x86 / ARM)或 Windows 电脑,家庭宽带最有价值。云服务器也欢迎:阿里云、腾讯云、华为云等国内云厂商的机器单独汇成"国内云厂商"池,境外机器只展示不分池。
  • 同一个 token 可以装在多台机器上,每台(不同网段)各算一票;一个池里每人最多算 5 台,且每个 IP 必须有 2 人以上认可。
  • 每次运行消耗几 MB 流量;不开放任何端口,不代理任何流量。
  • 这里只记录你线路所在的 /24 网段和运营商,不保存你的完整 IP。
  • 探针和本站的代码都开源在 github.com/1molchuan/cfhub:探针连哪些地址、上报什么都写在 README 里,安装的程序可以从源码逐字节复现,sha256 和安装脚本里的一致。
