加入:在你的线路上跑一个探针

探针每小时用 ECH 实测一批 Cloudflare IP(和浏览器访问 Cloudflare 站点的方式相同),把结果上报到这里。同一运营商有足够多的探针后,edge DoH 就会给这个运营商的用户返回更适合他们的优选 IP。

  • 只需要一台能长期开机的 Linux(x86 / ARM)、Windows 电脑或 OpenWrt 路由器,家庭宽带最有价值。云服务器也欢迎:阿里云、腾讯云、华为云等国内云厂商的机器单独汇成"国内云厂商"池,境外机器只展示不分池。
  • 同一个 token 可以装在多台机器上,每台(不同网段)各算一票;一个池里每人最多算 5 台,且每个 IP 必须有 2 人以上认可。
  • 每次运行消耗几 MB 流量;不开放任何端口,不代理任何流量。
  • 这里只记录你线路所在的 /24 网段和运营商,不保存你的完整 IP。
  • 探针和本站的代码都开源在 github.com/1molchuan/cfhub:探针连哪些地址、上报什么都写在 README 里,安装的程序可以从源码逐字节复现,sha256 和安装脚本里的一致。

安装命令

{{if not .NewToken}}

把命令里的 <你的 token> 换成你保存的 token。同一个 token 可以装在多台机器上,不用重新生成。

Linux(root 运行)

curl -fsSL {{.PublicURL}}/install.sh | sudo bash -s -- {{$t}}

缺少的依赖(curl、CA 证书等)会自动用系统的包管理器安装。

OpenWrt 路由器(SSH 登录后运行)

wget -qO- {{.PublicURL}}/install.sh | sh -s -- {{$t}}
  • 支持 x86_64、ARM(32 / 64 位)和 MIPS(如 MT7621、ath79)。需要约 10MB 空闲空间;不够的话在命令末尾加 --dir /mnt/sda1/cfprobe 装到 U 盘。
  • 每小时由 cron 运行一次,日志用 logread -e cfprobe 查看;升级固件后保留(已写入 /etc/sysupgrade.conf)。
  • 装了 OpenClash 的路由器:安装脚本会自动让探针绕过 OpenClash 直连,不用另外设置;OpenClash 之后再装的,重新运行一次安装命令即可。用 PassWall 等其他透明代理时,请在它的设置里让用户 cfprobe(或路由器自身的流量)直连,否则测到的是代理线路。--direct 选项绕不过路由器上的透明代理规则。

Docker(NAS 等)

docker run -d --name cfprobe --restart unless-stopped --network host -e CFHUB_TOKEN={{$t}} -v cfprobe-data:/data ghcr.nju.edu.cn/1molchuan/cfprobe:latest

支持 amd64、arm64 和 32 位 ARM。命令里用的是南京大学的 ghcr 镜像，大陆拉取快（实测阿里云上海 2 秒，直连 ghcr.io 要 2 分半）；境外机器把镜像换成 ghcr.io/1molchuan/cfprobe:latest。docker compose 写法见这里。日志用 docker logs cfprobe 查看。

Windows(以管理员身份打开 PowerShell)

& ([scriptblock]::Create((irm {{.PublicURL}}/install.ps1))) -Token {{$t}}

卸载:Linux 运行 curl -fsSL {{.PublicURL}}/install.sh | sudo bash -s -- --uninstall;OpenWrt 运行 wget -qO- {{.PublicURL}}/install.sh | sh -s -- --uninstall;Docker 运行 docker rm -f cfprobe && docker volume rm cfprobe-data;Windows 运行 & ([scriptblock]::Create((irm {{.PublicURL}}/install.ps1))) -Uninstall。
